# Mecha Thomas Resources

This folder is for **user-downloaded content** that supplements the committed index files.

## Why This Folder Exists

The `files/` directory contains our created indexes and quick references, which are small and committed to git.

This `resources/` folder is gitignored and holds larger texts you download locally for richer Thomistic research.

## Recommended Resources

### Summa Theologiae

| Source | Format | Notes |
|--------|--------|-------|
| [New Advent Summa](https://www.newadvent.org/summa/) | HTML | Benziger Bros. translation (1947); searchable |
| [Aquinas.cc](https://aquinas.cc/la/en/~ST) | HTML | Clean layout, parallel Latin/English |
| [DHS Priory](https://www.dhspriory.org/thomas/summa/index.html) | HTML | Dominican translation |
| [Internet Archive](https://archive.org/search?query=summa+theologiae+english+dominicans) | PDF | English Dominicans (1911-1912) |

## For Claude Web

If using Claude Web Projects, the index files provide structure. For deep research, consider uploading:
- Chesterton's *St. Thomas Aquinas* (for voice reference)
- Specific Summa sections relevant to current research

The full Summa is too large for Project Knowledge; use the indexes to guide web searches.
