# Mecha Alphonsus Resources

This folder is for **user-downloaded content** that supplements the project instructions.

## Why This Folder Exists

The `files/` directory contains our created indexes and references, which are small and committed to git.

This `resources/` folder is gitignored and holds larger texts you download locally for richer Marian research.
